# 미등록 값으로 개발하고 실제 조회로 전환하기

> 범위: 자료사전·코드사전·설정을 사용하는 개발 작업 | 성격: 사용자 요청에 따른 개발 가이드
>
> 언제 읽나: 사용할 사전·설정 값이 아직 등록되지 않았거나 등록 여부를 확인하지 못했을 때 | 읽지 않는 경우: 등록이 확인된 값만 쓸 때

사전·설정 등록 전에 에이전트가 화면을 실행·테스트하거나 개발자가 미리 확인할 수 있도록 임시값을 사용한다. 실제 조회 코드는 바로 아래에 일반 주석으로 남긴다.

1. 기존 키를 조사하고 등록 상태를 `확인됨 / 미등록 / 확인 필요`로 구분한다. 조회 권한이 없다는 이유만으로 미등록이라 단정하지 않는다.
2. 미등록·미확인 항목에만 임시값을 적용하고 `[임시값] 등록 후 아래 표준 코드로 교체`라고 표시한다. 등록할 키·언어는 코드와 종료 안내에 기록한다.
3. 임시값 바로 아래에 실제 조회 코드를 `//`로 주석 처리한다. 코드값·JSON 문자열·Map·숫자 등 소비 코드가 기대하는 자료형을 유지한다.
4. 화면 동작을 확인하고, 실제 사전·설정·캐시 연동은 미검증이라고 결과에 명시한다.
5. 작업 종료 시 아래 등록 안내를 제공한다. 등록 후 임시값을 삭제하고 실제 조회 코드를 활성화하여 다시 검증한다.

```javascript
// [임시값] 등록 후 아래 표준 코드로 교체
const pageTitle = '데이터모니터링';
//const pageTitle = /*[[${@cacheManager.getDicValue("Title", "DataMonitoring")}]]*/;

// [임시값] 각 title은 등록 후 바로 아래 표준 코드로 교체
const TABLE_COLUMNS = { Vm: [
    {data: 'vmname', title: 'VM명', width: '22%'},
    //{data: 'vmname', title: /*[[${@cacheManager.getDicValue("DataMonitoringColumn", "vmname")}]]*/, width: '22%'},
] };
```

- 예시는 Thymeleaf 화면의 JavaScript에 적용한다. 별도의 표준 script 블록으로 분리하지 않고 교체 위치에 붙여 둔다.
- 테이블은 `title`만 교체하고 `data`, 너비, 정렬, 날짜 처리 등 기존 구조는 유지한다. 항목 교체 시 쉼표도 확인한다.
- HTML 요소는 임시 요소 바로 아래에 실제 요소를 일반 HTML 주석으로 남긴다. 등록 후 임시 요소를 삭제하고 주석을 해제한다.
- `//`는 JS 실행을 막지만 Thymeleaf 표현식 평가는 막지 않을 수 있다. 이 방식은 화면 확인용이며 서버 의존성 제거를 보장하지 않는다.
- `/*[[...]]*/ '임시값'`의 뒤 값은 서버 조회 실패 시 대체값이 아니다. 실제 처리에서 `Unknown`이 나오면 그대로 반영된다.
- `getRenderCode` 대체값은 예를 들어 `'{"READY":"준비"}'` 형태의 JSON 문자열이다. Map을 쓰는 선택 목록은 같은 key/value 구조의 임시 항목으로 만든다.
- Java 설정 조회도 임시 할당 바로 아래에 원래 호출을 Java 주석으로 남긴다. 숫자·날짜 설정은 소비 코드의 검증을 유지한다.
- 외부 접속·인증·데이터 변경을 제어하는 설정에는 임의 운영값을 넣지 않는다. 로컬 모의값으로 제한하고 실제 연동은 미검증으로 남긴다.
- 화면 표시용 상태를 임의로 추가해 업무 API에 보내지 않는다. 기존 API 계약의 식별값을 사용한다.

작업 종료 시 반드시 제공할 등록 안내:

| 항목 | 기록할 내용 |
|---|---|
| 대상 | 환경, Admin 관리 경로, 자료사전/코드사전/설정 구분 |
| 등록값 | 카테고리·이름·언어별 값·순서·사용 여부 등 해당 입력 항목 |
| 영향 | 사용하는 화면·파일·변수와 기존 API 식별값 |
| 전환 | 임시 코드 위치, 실제 코드 활성화 방법, 캐시 초기화와 화면 재로드 |
| 검증 | 임시값으로 확인한 범위와 실제 조회 후 추가 검증할 범위 |

- 완료 전 `rg -n '\[임시값\]|TEMP-DISPLAY-VALUE' <수정 대상 경로>`로 잔여 위치를 확인한다. 이전 표식도 함께 검색한다.
- 임시값이 남으면 화면 확인 완료와 실연동 미완료를 구분해 전달한다. 운영 반영 완료로 보고하지 않는다.
- 실제 전환 후 `Unknown`, 언어별 표시, 선택 순서·값, API 전달값, 관련 포탈 캐시를 확인한다.
- 스킬은 적용 조건과 이 문서 읽기·실행 단계를, 에이전트는 등록 안내·전환 검증 책임을 연결한다. 본문을 복사하지 않는다.
- `develop-screen-feature`의 구현 단계(임시값 적용)와 검증·완료 단계(표식 잔여 확인·등록 안내 제공), `convention-reviewer`의 구현 검토(임시값 해제 확인)가 이 문서를 참조하도록 연결되어 있다.

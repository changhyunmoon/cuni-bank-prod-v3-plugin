# 반영 승인 형식

5단계에서 아래 세 부분을 이 순서로 제시한다. 해당 항목이 없으면 "없음"으로 적는다. 표 앞에 실행 모드, 입력 요약, 위임 여부를 한 줄씩 적는다.

## 1. 반영 계획 표

```
| # | 항목 요약 | 성격 | 근거 | 대상 문서·섹션 | 신규/갱신 | 라우터·링크 변경 |
```

- 항목 요약은 반영될 문장의 요지를 한 줄로 쓴다. 3단계 지식 항목 ID를 괄호로 붙인다.
- 대상 문서는 docs 기준 상대 경로와 섹션 제목이다. 신규 문서는 경로·사용할 템플릿·답하는 질문을 적는다.
- 한 문서에 여러 항목이 들어가면 문서별로 묶어 보여준다.

## 2. 충돌 표

```
| # | 대상 문서·위치 | 현재 문서 내용 | 새 정보 | 새 정보 근거 | 선택: 유지 / 교체 / 병기 / 제외 |
```

- 현재 문서 내용은 해당 문장을 짧게 인용하고 줄 번호를 붙인다.
- 병기는 적용 범위(모듈·환경·시점)로 구분해 둘 다 남기는 것이다. 구분 기준을 함께 적는다.
- 어느 쪽이 맞는지 판단하지 않는다. 근거의 종류(지침·코드·제공 정보)와 확인 날짜만 비교해 보여준다.
- 사용자가 선택하지 않은 충돌은 반영하지 않는다.

## 3. 제외 목록

```
| 제외한 정보 | 사유(원문 복사·로그·비밀값·중복·범위 밖) |
```

## 승인 요청 문구

표 아래에 다음을 묻는다.

- 반영할 항목(전체 또는 번호), 제외할 항목
- 성격을 바꿀 항목(특히 지침으로 올릴 항목)
- 충돌별 선택
- 새 문서 경로·이름 변경 여부

사용자의 수정 지시를 반영한 표를 다시 제시하고, "승인"을 받은 뒤에만 6단계로 간다.
